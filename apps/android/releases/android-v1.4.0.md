# Android v1.4.0 · 对话助手与数据备份

这版在原有任务管理和本地通知之外，加入了可选的对话助手。后续还有 1.4.1～1.4.3 的改进，日常使用建议下载最新版本；本版本作为历史版本保留。

> 安全提示：本版使用的 Capacitor Android 8.3.1 位于 [GHSA-rvm3-566m-v7fv](https://github.com/advisories/GHSA-rvm3-566m-v7fv) 的受影响范围内。1.4.1 起已升级至修复版本 8.4.3。请使用最新版，不建议安装或降级到本版。

## 新增

- 在设置里开启“对话助手”后，可直接从“查看任务”主界面右下角打开“聊聊任务”。日历、添加任务和设置页面不显示聊天入口；功能默认关闭。
- 助手可以普通聊天、查询任务，以及提出新增、修改和删除任务的建议。新增会列出任务信息，修改会对照修改前后内容，删除会提示核对；点击绿色确认后才会实际执行，红色取消不会改动任务。普通聊天和查询不需要确认卡片。
- 默认使用 DeepSeek V4.1 Flash，思考强度为 High，可在设置中切换关闭、Low、High、Max。
- 每次从主界面正常打开聊天都会开始新对话；空对话从预选问题池中随机显示两条建议。
- 对话历史保存在手机本地，可从设置中查看并继续之前的对话。清空只影响当前对话，不会删除任务或其他历史记录。
- 设置中增加“导出备份”：通过系统文件选择器导出 ZIP，包含任务、设置、壁纸和已保存对话，并附带校验信息。API 密钥不包含在备份中；本版暂不提供一键导入。

## 同时处理的问题

- 缩短主界面聊天入口，不再显示入口下方的说明小字。
- 调整清空对话的“取消 / 确认清空”按钮，避免窄屏下文字挤在一起。
- 对待确认操作加入重复点击保护和任务状态核对；未确认的操作不会因为停止回答或收起面板而执行。

## 历史记录与升级

由于上述旧容器漏洞，**本 Release 只保留源码和更新说明，不提供 1.4.0 APK 下载**。此前预置个人密钥的私用包也没有上传。

请直接下载最新版公开 APK。公开构建不预置 API 密钥，使用助手前需在设置中填写自己的 DeepSeek 密钥。沿用已有 Android 签名，从兼容签名的旧版本升级可直接覆盖安装；不要为了尝试旧版而卸载应用，以免清除本地数据。
