# Android v1.4.2 · 助手可以标记任务完成

之前助手只能新增、删除、修改和查询任务，这次补上“标记完成”。本版本保留作历史记录，日常使用建议下载最新版本。

## 新增标记完成

- 可以直接告诉助手“这个任务做完了”或“把某个任务标记完成”。助手会先查询并定位任务，再给出待确认卡片，不会只靠任务名称猜测目标。
- 完成卡片只展示一份任务信息，在同一张卡片内标出“进行中 → 已完成”，不再重复列两份内容。
- 点击绿色“确认完成”才会保存；点击红色“取消”保持原状。完成后任务仍保留在已完成列表中，并取消这项任务的后续提醒，不会被当作删除处理。
- 无截止时间或已经逾期的进行中任务同样可以完成。已经完成的任务不会重复操作；已归档任务不会直接标记完成。

## 防止错误操作

- 完成只修改任务状态和更新时间，不会顺带改标题、描述、截止时间或其他任务。
- 确认前再次核对任务是否仍与预览一致；若任务已经被编辑、完成、归档或删除，会拒绝过期确认并提示重新查询。
- 保留重复确认保护。历史中未完成的确认卡片不会在重新打开对话时自行执行。
- 助手的工具说明、界面说明和历史记录格式一并补上完成操作；只有实际确认成功后才向模型返回成功结果。

## 验证与安装

自动测试覆盖了确认、取消、重复确认、过期预览和提醒计划；并在荣耀真机上用临时任务完成了“新增 → 助手标记完成 → 查询核对 → 删除清理”的流程。

公开 APK 不预置 API 密钥，需要在设置中填写自己的 DeepSeek 密钥。沿用原签名，可直接覆盖升级，原有任务、对话和设置保留。旧版本仅留档，不建议降级。
