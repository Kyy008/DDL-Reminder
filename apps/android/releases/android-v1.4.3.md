# Android v1.4.3 · 收起提醒设置，连续确认多项操作

## 提醒设置不再占一长栏

- 设置里的“任务提醒”默认收起，保留标题、展开按钮和提醒总开关。检查步骤、临近提醒和紧急提醒时间在展开后查看、调整。
- 重新进入设置时仍默认收起。
- 收起只是界面变化，不会关闭提醒、改变提醒时间，也没有改动后台通知的实现。
- 如果有尚未保存的提醒设置变更，保存和取消按钮仍可见，避免收起后找不到待保存内容。

## 一条消息里处理多项任务操作

- 明确了助手的连续操作规则：同一轮可以提出多个新增、删除、修改或标记完成操作，不必每确认一项就重新发消息。
- 确认卡片依次出现，每项都必须单独确认；上一项的确认不会授权后面的任务。
- 取消只取消当前项，后续已经明确要求的操作仍会继续；点击“停止”或收起对话后，尚未确认的操作不再继续。
- 每项操作都从最新任务状态生成预览；同一个任务的后续操作需要重新查询。结果汇总区分已执行、已取消和失败，不会把取消项说成成功。

## 验证

176 项自动测试通过。本地界面检查覆盖默认折叠、窄屏/横屏/平板、保存设置、连续新增、连续删除，以及完成、删除、修改混合操作。

荣耀真机验证了连续新增三项、完成后接着删除和修改、中间取消后继续、停止剩余操作，以及连续清理三条临时任务。测试任务和本轮测试对话已清理，没有操作原有任务和聊天。

## 安装与密钥

本页公开 APK **不预置个人 API 密钥**，需在设置中填写自己的 DeepSeek 密钥；此前手机上使用的预置密钥私用包没有上传。签名与已有兼容版本一致，覆盖升级保留本地数据。

源码位于本仓库 `main` 分支的 `apps/android`。新安装建议直接使用本版本；历史版本仅供留档，不建议降级。

构建依赖审计仍有 Next.js 等服务端、构建工具相关告警；本次没有把所有依赖告警清零。Android 包采用静态导出，不运行 Next.js 服务器，也不打包 Node.js 构建环境。后续构建依赖升级需要单独回归。
