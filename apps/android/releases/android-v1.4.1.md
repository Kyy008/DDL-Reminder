# Android v1.4.1 · 修复聊天排版，补齐历史对话删除

本次更新主要解决助手回复看起来仍像原始 Markdown、公式无法显示，以及聊天面板操作不够顺手的问题。本版本保留作历史记录，建议日常使用最新版本。

## 修复回复排版

- 正确显示 Markdown 表格、粗体、斜体、粗斜体、标题、列表、引用、删除线、链接和代码，不再直接露出原本应该用于格式控制的星号。
- 修复中文标点附近的粗体、斜体识别，例如“**任务：**说明”这类写法。
- 支持行内及独立段落的 LaTeX 公式，包括美元符号和反斜杠形式的公式分隔符。代码片段、代码块中的公式符号仍作为代码保留，不会误转成公式。
- 表格、长公式和代码块可在内容区域内横向滚动，避免把整个聊天面板撑出屏幕；检查了窄屏、横屏和平板布局。
- 公式字体随应用打包，不依赖额外的在线字体服务。无效公式会保留可读内容，不会令整段回复消失。
- 回复中的原始 HTML 不会作为可执行页面插入，外部图片不会自动加载，危险链接会被过滤。

## 调整聊天操作

- 历史对话列表增加单条删除按钮，删除前使用独立的居中确认框；取消会保留原记录，确认只删除选中的对话，不会影响任务或其他聊天。
- 删除确认框处理了焦点、返回键和重复提交，避免误点到后方列表。
- 输入框初始高度与发送按钮一致，随多行输入增高；清空后会缩回单行高度，屏幕宽度变化时也会重新适配。

## 依赖更新

Capacitor 升至 8.4.3，包含 [GHSA-rvm3-566m-v7fv](https://github.com/advisories/GHSA-rvm3-566m-v7fv) 的修复；KaTeX 升至 0.19.0。任务存储方式、本地提醒和后台设置没有因这次聊天排版调整而改变。

## 安装

公开 APK 不预置 API 密钥，需要在设置中填写自己的 DeepSeek 密钥。沿用原签名，可覆盖升级并保留本地任务、聊天和设置。旧版本仅留档，不建议降级。
